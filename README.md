# 多莉国

日常英语学习网站：背单词、场景对话、阅读和复习可以分开用。

网站地址：[https://tianba-scp035.github.io/DoliGo/](https://tianba-scp035.github.io/DoliGo/)

当前公开预览还不是产品验收，也不算已经可以当作正式学习成品。学习记录只保存在你自己的浏览器里，不会写进这个仓库。

## 本地运行

```bash
npm install
npm run dev
npm test
npm run build
```

本地开发服务器默认是 `http://127.0.0.1:4174/`。日常验收请看上面的网站地址。
